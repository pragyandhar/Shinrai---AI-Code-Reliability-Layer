### .env VS .env.example?
#### ANSWER:
.env - stores secret keys

.env.example - stores the template of the secret keys

.env.example ka use local development me kiya jata hai taki ham apne code me env keys related errors na face karein

Actual me environment variables, they are managed by Secret Key Managers for example:

Cloud Providers:
- AWS Secret Manager
- Azure Key Vault
- Google Secret Manager

Multi-Cloud / Self Hosted:
- Hashicorp Vault
- Infisical
- Doppler

CI/CD
- Github Actions Secret
- GitLab CI/CD variables
- Jenkins


Abb yeh actual app me use kaise hota hai jab hamne code me to templates pass kiye hue hai:

Maan lijiye ki aap koi VPS (Virtual Private Server) pr apna app run kar rhe hai.
Aur aapko koi task run karne ke liye permission ki zarurat hai. To aap environment variables me jo secret keys pade hai unka use karke aap apne task ke liye permissions lenge. 

Abb aapko vo secret keys access karne jo bhi Secret Key Manager aapne choose kiya hai usko ek call lagayeinge aur vahan se os.getenv() method ka use krke apne secret key ko access kareinge.

Uska baad aapka task execute hoga.

- Follow Up: What is VPS?

VPS stands for Virtual Private Server

Yeh ek physical server ko multiple virtual servers me divide karne ke tarike ko bolte hai.

Har ek virtual server ke paas apne khud ka:
- os
- IP address
- CPU allocation
- Memory
- Storage

hota hai. 

Aap VPS providers se koi bhi aur kitne bhi VPS rent kar sakte hai.

Examples ke liye:
- DigitalOcean
- Linode
- Vultr
- Hostinger
